# 灰燼墓誌深層平衡

基準版本：`631d56f`（無盡遠征，尚未加入深層規則）。
比較資料：`baseline.json` 與 `balanced.json`。

## 測量方式

每個職業使用種子 1–100，分別測試傳承 0、5 級與防守／進攻兩種策略，共 1,200 次遠征。所有動作都經過正式 reducer，不改生命、裝備或敵人，也不偷看隨機種子。各次模擬直到死亡、通過第 100 層，或超過 20,000 次操作為止；本次沒有流程停滯。

兩版使用相同的選路、裝備評分與技能策略。防守策略在生命低於 55% 時優先癒合，並盡量守夜抵擋每第三回合重擊；進攻策略在生命低於 20% 時才優先癒合，不主動守夜。兩者均選擇可取得成長與回復的路線，裝備依攻擊、生命、護甲、命中回血評分替換。技能保留職業起始五格，不學習新技能。

這是可重現的回歸基準，不是玩家死亡機率估計、最佳策略搜尋，也未涵蓋所有技能組合。高層數不會觸發程式強制結束；樣本最遠抵達第 70 層不代表遊戲有 70 層上限。

```sh
npm run balance:ashbound -- balanced 100
```

此命令用目前模型產生 `reports/ashbound/balanced.json`。`baseline.json` 是修改模型前，使用同一支模擬器在 `631d56f` 測得的資料。

## 採用的規則與理由

- **漸進壓迫**：第 11 層起，原有敵人生命乘上 `1 + (層數 − 10) × 2%`，攻擊乘上 `1 + round((層數 − 10) × 1.2)%`。提高深層成長速度，避免玩家與敵人線性成長後，難度永遠維持在同一比例。
- **可預覽的特性**：破甲使蓄力重擊忽略一半護甲，但守夜減傷仍有效；枯萎讓戰鬥回血減少 30%，鼓勵營地整備；骨鎧降低直接傷害 20%，毒素可繞過。特性依層數與房間輪替，不會因重新整理改變。
- **久戰狂怒**：深層戰鬥第 9 回合攻擊 +15%，每多一回合再 +15%，無倍率上限。可從倒數與預計承傷判斷何時該進攻，避免無限回血拖延。沒有傷害以外的強制死亡條件，新遭遇重置狂怒。
- **深層技能成長**：汲取按實際傷害回血且最多 15% 最大生命，裝備命中回血另計；毒素每層傷害為攻擊的 6% 無條件捨去，至少 3。保留兩種流派的用途，縮小深層固定毒傷與高倍率回血的差距。
- **存檔相容**：既有戰鬥保留原屬性與規則，下次新遭遇才採用深層機制；戰後回血、傳承、裝備與魂燼不因更新重置。

## 回歸檢查

`deep.test.ts` 驗證壓迫起點、預計承傷與實際扣血一致、守夜抵擋破甲、枯萎的作用範圍、汲取上限與溢出傷害、骨鎧與毒素、狂怒開始與重置、回血循環最終死亡、舊存檔相容與非法特性拒絕。每職業另用 20 個固定種子確認第 20 層可突破且後期有實際死亡。

原有的第 1,001 層測試只驗證流程與存檔，會把敵人生命設為 1；它不是平衡或生存率測量。
